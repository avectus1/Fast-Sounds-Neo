# FastSounds Neo

A NeoForge 1.21.1 port of [FastSounds](https://github.com/shuttheirprayer/Fast-Sounds) by Misanthropy.

It makes Minecraft's sound engine lighter by skipping sounds you can't really hear, limiting sound spam, and starting sounds without making the game wait. Client side only.

Based on Leandrohunter's unofficial 1.21.1 port and the FastSounds 0.6 source. See `NOTICE` for what changed.
